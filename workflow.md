## Two pipeline modes
- **Highlight-reel ("Director" cut)** — 5-6 min hype cut, best moments out of order,
  hard cuts + burned-in verbatim captions, single merged output video.
- **Explainer (narrated recap)** — chronological narrated recap. Produces per-beat
  `Clip-N.mp4` (video-only) / `voice-N.mp3` pairs — **no merged final video**, by
  explicit design; you assemble the final cut yourself. English-only for now.

## How we communicate / workflow between us
1. You paste a server log or describe what happened → I diagnose
2. I edit files in the cloud sandbox → sync to your PC via the device bridge
3. Server auto-reloads (`reload=True`) → you re-run the job from the dashboard
4. Repeat until it's clean, then move to the next feature/stage
5. Never edit/push pipeline files while a job is running on your machine — auto-reload
   restarts the server process and kills the in-progress background thread
6. Major direction changes get discussed and confirmed before I build — not
   build-then-review

## Queued for next upgrade
- **Gemini-instructed camera/transition effects (Zoom In/Out, Slide, Burn, Fly)** —
  proposed 2026-08-27, not yet built. Assessed as feasible: Gemini would tag an
  effect per clip via a constrained schema enum (same pattern as `scene_type`/
  `beat_role`), and Python maps each tag to a fixed, pre-tested ffmpeg filter — no
  filter code ever generated by the model.
  - **Within-clip motion** (Ken Burns-style zoom/pan) — ffmpeg's `zoompan` filter,
    applies to a single clip, no merging required. Fits either mode as-is.
  - **Between-clip transitions** (slide, wipe, a flash "burn" handoff, dissolve) —
    ffmpeg's `xfade` filter (~50 built-in named transitions, including
    `slideleft`/`slideright`, `wipeup`/`wipedown`, `zoomin`, `fadewhite`/`fadeblack`,
    `dissolve`, `circleopen`, etc.), but this only exists at a seam between two
    MERGED clips. Highlight-reel mode already merges clips and already has a
    `TRANSITION_TYPE` setting (`cut`/`fade`) — extending that list is a natural fit.
    Explainer mode does NOT currently merge clips by explicit design — inter-clip
    transitions can't apply there unless that no-merge decision is revisited
    specifically for this feature.
  - Open questions before scoping: highlight-reel only, or also revisit Explainer's
    no-merge rule; what "Burn" and "Fly" specifically mean (guessed: a flash-transition
    and a zoom+slide combo — not yet confirmed); whether Gemini chooses the effect
    freely per clip, or effects are fixed by `beat_role` (e.g. hooks always get a
    punchier transition).
